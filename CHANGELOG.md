# Changelog

All notable changes to **VibeCatcher** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-26

### Added
- 🚀 Initial open-source release of VibeCatcher.
- 🎯 Automated Instagram Reel trigger keyword commenting engine.
- 📥 Real-time Playwright persistent browser DM response capture.
- 🔗 Deep link & resource extractor (Google Drive, PDFs, Notion, external URLs).
- 📄 PDF report builder (`consolidated_report.pdf`) with extracted resource links.
- 🎨 Modern ultra-sharp dark glass UI with 3D card tilt interactions.
- ⚡ One-click PowerShell (`run.ps1`) and CMD (`run.bat`) launchers.
